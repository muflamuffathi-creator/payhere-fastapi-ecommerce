Exposing Local Server for Live PayHere Sandbox

PayHere requires a publicly reachable notify_url to send its server callback. To test live with the official PayHere Sandbox checkout page and test cards:

  1. Install ngrok: If not installed, download from ngrok.com or run choco install ngrok / winget install ngrok.
  2. Start public tunnel: 
    ngrok http 8000
  3. Copy your HTTPS URL: (e.g. https://abcd-12-34-56-78.ngrok-free.app).
  4. Update .env file: 
    BASE_URL=https://abcd-12-34-56-78.ngrok-free.app
PAYHERE_MERCHANT_ID=your_merchant_id
PAYHERE_MERCHANT_SECRET=your_merchant_secret
  5. Test Checkout: Perform a test checkout on the storefront. PayHere will POST directly to your ngrok tunnel at /api/v1/payments/payhere/notify!
