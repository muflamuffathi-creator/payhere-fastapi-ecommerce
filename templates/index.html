Under the Hood

How PayHere Sandbox Integration Works

Industry standard, cryptographically validated payment processing flow between FastAPI and PayHere.

1

Order Reservation

Customer submits checkout details. FastAPI validates prices against the database, reserves product stock, and generates an authoritative order number.

POST /api/v1/orders
2

MD5 Hash Signing

The backend calculates PayHere's tamper-proof MD5 checkout hash using Merchant ID, Order ID, 2-decimal formatted amount, currency, and MD5 hashed secret.

UPPER(MD5(id + order + amount...))
3

Sandbox Gateway

Customer is forwarded to PayHere Sandbox checkout modal or hosted page. Test credit card details can be entered with zero real-world cost.

sandbox.payhere.lk/pay/checkout
4

Webhook Signature Check

PayHere asynchronously POSTs to notify_url. FastAPI validates md5sig, records payment audit trails, and transitions order to PAID.

POST /payments/payhere/notify
